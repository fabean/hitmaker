Hitmaker's first release: a terminal workspace for writing and arranging songs for Suno.

- Reusable lyric sections and a live arrangement preview.
- Vim-style navigation, editing, clearing, and copying.
- 85 styles and 23 arrangements, plus custom presets from `~/.config/hitmaker/`.
- Autosaved song data and timestamped Markdown snapshots.
- Clipboard integration and separate lyrics, style, and title exports.

Download the archive for your operating system and CPU below. Linux and macOS builds include amd64 and arm64; Windows includes amd64. Each archive contains the executable, README, and custom preset examples. `SHA256SUMS` provides SHA-256 checksums for the archives.

Alternatively, with Go 1.25 or newer:

```sh
go install github.com/fabean/hitmaker@v0.1.0
```

Terminal and desktop integration has been exercised on Linux. macOS and Windows binaries are cross-compiled; please report platform-specific issues on GitHub.
